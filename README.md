# Continuous-Age-Dependent-Analysis-of-Somatic-Mutation-Profiles-and-Survival-in-PDAC-
An in-depth analysis of mutation profiles and survival rates in patients with Pancreatic Ductal Adenocarcinoma. Cox proportional hazards, multivariate regression, and Kaplan-Meier survival curves were utilized to analyze PDAC patient records from The Cancer Genome Atlas.
